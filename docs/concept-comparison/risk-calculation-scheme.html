БДУ ФСТЭК

227 УБИ загружены в БД

Каждая запись содержит источник угрозы, потенциал нарушителя, объект воздействия и последствия по конфиденциальности, целостности, доступности.

концепт

S -> ST -> VL -> методы -> DA

Канонические справочники и матрицы связей вынесены в отдельные таблицы ПТСЗИ, а не смешаны со старой картой риска.

расчет

W_i по активу

W = (Q_threat + q_threat + (1 - Qreaction)) / 3 * Z

Сценарий актуален только через пересечение VL угрозы и VL конкретного актива.

Маппинг источников БДУ к PDF-концепту

Источник в УБИ ФСТЭКИсточник концептаЛогика
Внутренний нарушитель, любой потенциалS3Персонал организации
Внешний нарушитель, низкий потенциалS4Хакеры/мошенники без устойчивого ресурса
Внешний нарушитель, средний/высокий потенциалS1, S2, S4Может быть конкурент, партнер с доступом или сильный внешний атакующий
Один фрагмент БДУ может давать несколько источников S, потому что БДУ описывает тип нарушителя, а PDF описывает бизнес-роли.

Как БДУ влияет на расчет

Поле УБИИспользование
Потенциал нарушителяlow=0.33, medium=0.66, high=1.00 для Q_threat
К/Ц/Д последствия1 свойство = 0.33, 2 = 0.66, 3 = 1.00 для q_threat
Объект воздействияПоказывает, что именно атакуется: трафик, ПО, узел, данные, инфраструктура
Идентификатор УБИДает нормативную ссылку в сценарии, графе и отчете

Пример УБИ.001

Внешний нарушитель со средним потенциалом; Внутренний нарушитель со средним потенциалом

Маппинг: S1, S2, S3, S4.

Последствия: К + Ц + Д, поэтому опасность высокая.

Пример УБИ.002

Объект воздействия: сетевой трафик; нарушение конфиденциальности

Маппинг: S1, S2, S4.

Хорошо ложится в сценарий ST4 Перехват трафика.

Пример W для актива

ST2: Q=0.50, q=0.70, R=0.73298, Z=1

W = (0.50 + 0.70 + (1 - 0.73298)) / 3 = 0.48901

Уровень: medium. Недостающие методы повышают Qreaction и снижают W.

Что ставить рядом с PDF-листами

  • Для “источников и угроз”: таблицу маппинга БДУ -> S1..S4.
  • Для “уязвимых звеньев”: матрицу ST -> VL и пример УБИ как доказательство сценария.
  • Для “методов”: матрицу VL -> A/FW/IDS/... и чекбоксы методов актива.
  • Для “формулы”: блок actual_vls, Qreaction, Z, W.
