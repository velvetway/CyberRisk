Как показать на листе

Справа от исходной таблицы поставь компактную таблицу “Концепт → БД/API”. Для доказательства можно добавить кусок результата SQL:

Что важно честно написать

В PDF перечислены 8 базовых угроз ST1..ST8. В системе они не ограничены восьмёркой: есть демо-угрозы, угрозы ФСТЭК и поля для БДУ. SQLite-снапшот БДУ лежит в data/bdu.sqlite: 86 664 уязвимости, 715 615 записей ПО, 114 483 CVE.

Что лучше не скрывать

Аббревиатуры методов из PDF не перенесены в интерфейс как отдельные коды. В реализации они представлены через реальные controls: WAF, patch management, database access control, network segmentation, backup, IDS, training.
