# Сопоставление PDF-концепции и реализации CyberRisk

Готовый файл для вставки в работу:

- [index.html](./index.html) — 8 листов: слева страница исходной PDF-концепции, справа реализация в проекте.
- [risk-calculation-scheme.html](./risk-calculation-scheme.html) — визуальная схема ПТСЗИ для вставки рядом с PDF-концептом.
- [risk-calculation-scheme.md](./risk-calculation-scheme.md) — актуальная текстовая схема реализации: 227 УБИ ФСТЭК, маппинг внешнего/внутреннего нарушителя к `S1..S4`, расчет `W_i`, примеры.
- [concept-pages/](./concept-pages/) — извлеченные страницы PDF как PNG.

Как использовать:

1. Открой `docs/concept-comparison/index.html` в браузере.
2. Проверь масштаб. Лучше печатать в PDF в альбомной ориентации, поля `none` или `minimum`.
3. Если нужен живой скрин интерфейса, используй запущенный проект:
   - `http://localhost:3000/assets` — реестр активов.
   - `http://localhost:3000/risk/map` — карта рисков.
   - `http://localhost:3000/risk/preview` — симулятор риска.
   - `http://localhost:3000/ptszi/model` — новая страница ПТСЗИ: актив, VL, методы защиты, сценарии ST, УБИ ФСТЭК и расчет `W`.

Логин на свежей тестовой базе: `admin` / `admin123`.

Суть сопоставления сейчас:

- Канонические `S1..S4`, `ST1..ST8`, `VL1..VL7`, методы `A/FW/IDS/...`, `DA1..DA7` и матрицы связей вынесены в отдельную модель ПТСЗИ.
- Таблица УБИ ФСТЭК загружена в БД: 227 записей с источником угрозы, потенциалом нарушителя, объектом воздействия и последствиями по К/Ц/Д.
- Источник БДУ `внешний/внутренний нарушитель + потенциал` сопоставляется с исходными источниками концепта `конкуренты / партнеры / персонал / хакеры`.
- Расчет `W_i` идет по применимому сценарию: `ST`, актуальные `VL` актива, внедренные методы защиты, `Qreaction`, `Z`, УБИ-примеры.
- Старая карта `Impact × Likelihood` остается отдельным legacy-экраном, основная реализация концепта находится на `/ptszi/model`.
